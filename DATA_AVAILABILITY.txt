Data availability statement for the thesis:

Data and code availability. The analysis code (Google Earth Engine and Python scripts), the intermediate data exported from Earth Engine, the ČHMÚ station and streamflow records used, and all result tables and figures are provided in the accompanying archive attached to this thesis, and are also available at https://github.com/iamnabid/thesis-snow-cover-analysis. The archive contains a README with the order in which the scripts are run and the version of every software package used. The Python analysis can be rerun from the archived data without Earth Engine access; regenerating the Earth Engine exports requires an Earth Engine account and a user-defined Cloud project. All source datasets are publicly available: MODIS MOD10A1/MYD10A1 v6.1, Copernicus GLO-30, Hansen Global Forest Change, WDPA, ERA5-Land and Sentinel-2 through Google Earth Engine, and station snow-depth and streamflow records from the ČHMÚ open-data portal (opendata.chmi.cz, CC BY 4.0).
